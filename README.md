# Luma Design Studio

A responsive landing page for a fictional independent design studio.

## What was built

- A responsive single-page studio website with navigation, hero, work showcase, approach, contact, and footer sections.
- Custom visual styling, responsive mobile layout, smooth scrolling, and a mailto contact link.
- A lightweight project with no build step or external framework required.

## Tools used

- HTML for page structure
- CSS for layout, responsiveness, typography, and visual design
- JavaScript for small browser interactions
- Google Fonts for typography

## Run locally

Open `index.html` in any web browser. No installation or backend server is required.
